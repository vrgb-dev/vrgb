# Privacy Policy

This repository contains open-source software and related development projects.

The software is designed to operate locally on users' devices. The project maintainers do not operate a centralized service that collects, sells, or shares personal information through these applications.

Certain optional integrations may connect to third-party services with the user's authorization. Such integrations access only the information permitted by the user and required for their intended functionality.

Authentication credentials and application data are generally stored and processed locally, except where communication with an authorized third-party service is necessary.

Users can revoke access granted to third-party integrations through the relevant service provider's account settings.

For privacy-related questions, please contact the project maintainers through the repository's GitHub Issues page.
